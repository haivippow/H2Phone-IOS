# Full Process Profile Design

For a selected app while Fake is ON, return the selected profile from all implemented app and framework call paths in that process, including Darwin/kernel version, SystemVersion plist/bundle reads, legacy web views, cached User-Agent values, and outgoing request User-Agent headers. The user explicitly accepts that WebKit/UIKit may receive a false OS version and crash or choose incompatible code paths. Native `UIScreen` remains real because changing layout geometry already caused a confirmed Safari keyboard defect; browser JavaScript screen values remain fake.
